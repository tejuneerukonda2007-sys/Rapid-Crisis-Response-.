# 🚨 Rapid Crisis Response

AI-powered emergency response system for faster and smarter crisis management.

## 📌 Problem
- Delay in response time
- Poor communication
- Lack of real-time data

## 💡 Solution
- One-tap SOS alert
- Live location sharing
- Connect victims with responders

## 🚀 Features
- SOS Button
- Location Tracking
- Map View

## 🛠️ Technologies
- Firebase (future)
- Google Maps
- HTML, CSS, JavaScript

## 📂 How to Run
Open index.html in browser
